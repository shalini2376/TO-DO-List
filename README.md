## TO-DO List

A simple and clean TO-DO List application built using **HTML, CSS, and JavaScript**.  
It allows users to add tasks, delete tasks, and automatically saves the task list using **localStorage** so data persists even after refreshing the page.

## ✨ Features
- Add new tasks using the input field  
- Show a warning message if the task input is empty  
- Delete tasks individually  
- Tasks are saved in **localStorage**  
- Responsive and lightweight UI  

## 🛠 Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **localStorage API**

## 🚀 How to Run Locally

1. Clone the repository:
   
```
  git clone  https://github.com/shalini2376/TO-DO-List.git
```

2. Open the project folder.
   
3. Open index.html in your browser.

No additional setup needed — it's a fully static project.
